# 05 — 教材系统

教材系统负责 PDF 渲染、页码到章节的映射、页面标记和教材偏好持久化。

## 页码映射

核心设计：用确定性的页码→章节映射替代向量检索。

```
PDF 书签 (PyMuPDF 提取)
  +
MD 正文标题 (正则解析 34 个节级标题)
  │
  └─ 按章节号匹配 → textbook_sections 表
     │
     └─ sequence_id（节级 ID，如 `V1-C01-S03`）+ content (MD 全文) + page_range
```

每次提问时，`get_page_context(textbook_id, page)` 直接查 SQLite 获取当前页对应的章节 MD 原文，不再依赖向量相似度搜索。

## 教材渲染

[PDFViewer.tsx](../frontend/src/components/PDFViewer.tsx) — 核心组件：

- **PDF 渲染**：使用 `react-pdf` 逐页渲染
- **翻页**：支持滚动翻页、页码跳转、目录导航
- **适应平板**：竖屏模式全屏 PDF + 浮动 AiBall 提问球
- **双页视图**：桌面端可选双页并排

## 页面标记系统

[PageMarker.tsx](../frontend/src/components/PageMarker.tsx) — 学生提问后，教材对应位置出现标记圆点：

- **标记类型**：`screenshot`（截图提问）/ `text`（文字提问）两类；文字标记显示在页面左侧（蓝色），截图标记显示在右侧（红色），同一页多个标记用序号区分
- **位置**：`marker_y_ratio` 记录标记在页面中的纵向比例，跨页/翻页后仍定位在提问处
- **持久化**：标记写入 `chat_history` 表的字段（`marker_type` / `marker_y_ratio` / `thumbnail` / `page_number` 在 connection.py L50-62，`crop_bbox` 在 L73 的补字段块），由前端在提问时 `POST /api/chat/history` 创建、SSE 完成后 `PATCH /api/chat/history/{chat_id}` 补 answer；不再有独立的 `textbook_progress` 表
- **阅读位置**：当前阅读页码持久化在 `math_profiles.last_page_number`（连同 `last_textbook_id`，经 `POST /api/profile/textbook-preference` 保存）
- **悬停弹窗**：[MarkerPopover.tsx](../frontend/src/components/MarkerPopover.tsx) 显示标记详情，KaTeX 渲染公式

## 教材章节结构

`textbook_sections` 表存储了 35 条章节记录（34 节 + 1 答案区）：

```sql
CREATE TABLE textbook_sections (
    id TEXT,
    textbook_id TEXT,      -- "高代上-丘维声"
    sequence_id TEXT,      -- "V1-C01-S03"
    chapter_name TEXT,     -- "行列式的展开"
    content TEXT,          -- MD 原文全文
    start_page INTEGER,    -- 章节起始页
    end_page INTEGER       -- 章节结束页
);
```

## 教材选择

教材选择由前端 [useTextbookPreference.ts](../frontend/src/hooks/useTextbookPreference.ts) hook 管理，后端提供 `GET/POST /api/profile/textbook-preference`（[profile.py](../app/routers/profile.py) L30/L40）：

- 登录用户：云端偏好优先（`math_profiles.last_textbook_id` / `last_page_number`），localStorage 兜底
- 匿名用户：仅从 localStorage 恢复
- 切换教材时同步保存到 localStorage + 云端（匿名登录后经 `/api/chat/migrate` 迁移标记）
