# 06 — 用户认证

用户认证模块提供注册、登录、匿名访问和 Token 管理。

## 三种登录方式

| 方式 | 端点 | 说明 |
|------|------|------|
| 注册 | `POST /api/auth/register` | 用户名 + 密码 + device_id |
| 登录 | `POST /api/auth/login` | 用户名 + 密码 → JWT |
| 匿名 | `POST /api/auth/anonymous` | 仅 device_id → 自动创建账户 |

匿名访问：首次请求时系统用设备 ID 自动创建账户（用户名 = `user_{device_id[:8]}`，空密码），返回 JWT。后续同设备自动登录。

## JWT 认证

- **签发**：[jwt_handler.py](../app/auth/jwt_handler.py) 使用 HS256 + `JWT_SECRET`
- **载荷**：`{user_id, username, exp}`
- **过期**：默认 30 天（`ACCESS_TOKEN_EXPIRE_DAYS = 30`，jwt_handler.py L9）
- **验证边界**：
  - 免验证：`POST /register`、`POST /login`、`POST /anonymous`（获取 token 的入口本身不需要 token）
  - 需验证：其余 `/api/auth/*` 端点通过 `Authorization: Bearer <token>` 头部验证（如 `/me`、`/math-profile`、`/insight`、`/diagnostic-cards`、`/knowledge-graph` 等），token 无效返回 401
  - QA 例外：`POST /api/qa/solve-stream` 同时接受 **body 的 `token` 字段**（qa.py L58-75，优先于头部解析，无 token 时按 device_id 生成匿名 user_id）

## 用户画像基础信息

[BasicInfoEditor.tsx](../frontend/src/components/BasicInfoEditor.tsx) — ProfilePanel 内置编辑器：

- 年级选择（大一/大二/大三/大四/研究生/自学）
- 薄弱点编辑（逗号分隔自由输入）
- 保存后写入 `user_profiles` 表

## 后端结构

```
auth.py:
  /register       → save_user + save_user_profile + sign JWT
  /login          → verify_password + sign JWT
  /anonymous      → 查 device_id → 有则返回，无则创建
  /me             → get_user_by_id → profile
  /profile        → update user_profiles
  /math-profile   → get_math_profile (15维)         (GET, L182)
  /math-profile   → update math_profiles            (PUT, L236)
  /knowledge-stats → get_knowledge_stats
  /diagnostic-history → get_question_assessments
  /knowledge-graph   → 知识图谱 API (v4.4)
  /insight           → 学习洞察报告（24h 缓存优先）
  /insight/regenerate → 强制重新生成洞察报告
  /diagnostic-cards  → 诊断卡片（source_code / evidence_span / rule_cases）
```
