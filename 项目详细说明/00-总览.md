# 00 — 架构总览

## 当前定位

项目当前对外名称建议为 **学数有道**，定位为"基于学科知识图谱的大学数学认知诊断与个性化导学智能体"。原有架构中的问答、画像、知识图谱、智能出题和对话管理，不再只服务"高等代数智能问答"，而是共同形成认知诊断闭环：根据学生真实学习过程判断其为什么不会，并给出可解释、可追踪、可验证的个性化干预。

详细竞赛定位见 [09-竞赛定位与认知诊断闭环](09-竞赛定位与认知诊断闭环.md)。

## 板块依赖关系

```
09-竞赛定位与认知诊断闭环
                   │
06-用户认证 ──→ 01-智能问答 ──→ 07-对话管理
                   │
                   ├──→ 02-学生画像 ←── 03-知识图谱
                   │        │
                   ├──→ 04-智能出题
                   │
                   ├──→ 05-教材系统
                   │
                   └──→ 08-截图交互
```

**核心链路**：认证（06）是入口 → 问答（01）是主流程 → 对话管理（07）沉淀学习证据 → 画像（02）+ 图谱（03）形成认知诊断大脑 → 出题（04）输出补救练习。教材（05）和截图（08）是输入通道，竞赛定位（09）定义这些模块共同服务的产品主线。

V2 阶段新增的三条服务端链路（模块 README 见 `app/services/` 各子目录）：

```
01-智能问答 ──→ 教学控制（intervention_service）──→ 练习（practice）
   每轮回答产出 tutor_directives / intervention_actions，练习草稿由干预动作触发，
   practice 作答写 practice_attempts；exercise 提交写 exercise_attempts。
   V2 诊断消费 qa_turn_records 与 exercise_attempts 两个评分源。

02-学生画像 ──→ 诊断 V2（分源评分 → 证据账本 → 确定性投影）
   QA turn / exercise attempt 分别评分，写入 diagnostic_evidence 证据账本，
   再由确定性投影器更新 knowledge_stages / math_profiles（当前 shadow 档位只记证据不改画像）。

01-智能问答 ──→ 数学可视化（create_math_visualization 工具）
   工具产物经 ToolRuntime.artifact_handler 落库（math_visualizations / animation_jobs），
   以 visualization SSE 事件推给前端；动画由后台 Manim worker 渲染。
```

## 数据库表概览

SQLite 共 **45 张表**（含 SQLite 内部序列表 `sqlite_sequence`，业务表 44 张），按域分组如下。DDL 全部收敛在 [connection.py](../app/db/connection.py) 及三个子 schema（`chat_tree_db.py` / `visualization_db.py` / `tool_trace_db.py`）。

### 用户与认证（2 张）

| 表 | 用途 | 主要读写 |
|----|------|---------|
| `users` | 用户账户（username / password_hash / device_id） | 注册/登录时写入 |
| `user_profiles` | 用户基础画像（grade / weak_points / strong_points / learning_preferences） | 手动编辑 |

### 教材（2 张）

| 表 | 用途 | 主要读写 |
|----|------|---------|
| `textbooks` | 教材注册表（name / subject / chapters） | 教材导入时写入 |
| `textbook_sections` | 教材章节页码映射（sequence_id / start_page / end_page / content） | 问答与出题时查询 |

### 问答与对话（11 张）

| 表 | 用途 | 主要读写 |
|----|------|---------|
| `qa_turn_records` | QA 事实记录主表（完整 context_snapshot / messages_snapshot） | QA 异步持久化写入，诊断消费 |
| `chat_history` | 前端对话历史 + 页面标记（marker_type / marker_y_ratio / thumbnail / crop_bbox） | 前端写标记，SSE 完成后补 answer |
| `chat_logs` | 后端对话日志（兼容写，旧诊断消费） | turn_store 兼容写 |
| `chat_trees` / `chat_nodes` / `chat_messages` | 对话树三件套（规范化树形对话存储） | 树对话路由写入 |
| `chat_node_references` | 树节点间显式引用（引用其他分支消息） | 树对话路由 |
| `node_summaries` | 节点摘要（versioned，源消息追溯） | 摘要生成 |
| `summary_trees` / `summary_nodes` | 学习摘要树（conclusion / misconception / open_question） | 摘要 API |
| `screenshot_context_cache` | 截图上下文缓存（image_hash / locator_signals / vision_summary / vision_extraction） | 截图问答读写 |

### 画像与认知状态（7 张）

| 表 | 用途 | 主要读写 |
|----|------|---------|
| `math_profiles` | 15 维素养分数 + weak_points + latest_diagnostic_report + last_textbook_id + last_page_number | 诊断投影写入，问答只读 |
| `knowledge_stages` | 每个概念的认知阶段 0-5（user_id + concept_name 唯一） | 诊断投影写入，脚手架/图谱读取 |
| `pending_stage_updates` | stage 更新队列（V2 已无生产写入方，保留表用于审计/兼容） | pending_worker 消费 |
| `question_assessments` | 诊断快照历史（15 维分数 + overall_score + weak_points + summary） | 诊断写入 |
| `user_knowledge_stats` | 知识点提问统计（topic / consecutive_turns / total_asks） | 问答时更新 |
| `dialogue_knowledge_states` | 对话概率状态（"用户-知识点" Stage 0-5 概率分布，影子消费者） | dialogue_state 投影 |
| `dialogue_state_projection_log` | 对话概率状态每次更新/弃权日志（可重放） | dialogue_state 投影 |

### 练习（9 张）

| 表 | 用途 | 主要读写 |
|----|------|---------|
| `exercise_bank` | 旧版 LLM 生成题库（question / answer / hints / source='llm'） | 旧出题链路 |
| `exercise_user_state` | 每用户练习可变状态（hint_level / is_answered / grading_status） | 练习提交 |
| `exercise_items` | 教材优先练习题池（不可变题目模板，source 默认 'textbook'，kg_mapping_status 校验） | practice 模块读取 |
| `exercise_attempts` | 练习作答证据（is_correct / hint_level / error_analysis / grader_version） | 提交时写入，诊断 V2 消费 |
| `practice_drafts` | 练习草稿（context_hash 幂等去重，queued→ready/failed） | practice worker |
| `practice_draft_items` | 草稿-题目关联（branch_role：diagnostic / remedial / verify / advance） | practice worker |
| `practice_sessions` | 练习会话（active → completed / inconclusive） | practice 服务 |
| `practice_attempts` | 会话内作答（verdict 四档 + evidence_quotes + rubric_findings） | practice 服务 |
| `practice_hint_events` | 提示事件（hint_level 1-3） | practice 服务 |

### 教学控制与干预（4 张）

| 表 | 用途 | 主要读写 |
|----|------|---------|
| `tutor_directives` | 每轮教学指令（teaching_goal / qa_policy / action：no_action / adjust_qa / offer_practice_entry / prepare_practice） | intervention service |
| `intervention_actions` | 干预动作（offer_practice_entry / prepare_practice + trigger_kind） | intervention service |
| `intervention_agent_jobs` | 干预 agent 任务队列 | intervention worker |
| `exercise_agent_jobs` | 练习 agent 任务队列（plan / author / review） | practice worker |

### 诊断 V2（6 张）

| 表 | 用途 | 主要读写 |
|----|------|---------|
| `diagnosis_runs` | 每次评分运行记录（source + scorer 幂等唯一，审计） | 诊断 scorer |
| `diagnostic_evidence` | 证据账本（StageObservation / DimensionObservation，带 strength 与 student_quote） | 诊断 scorer 写入，投影器消费 |
| `diagnostic_signals` | 学习信号（concept_confusion / prerequisite_gap / hint_dependency 等） | 诊断 scorer |
| `diagnosis_snapshots` | 评分快照（发布给 intervention 的控制面） | v2_service |
| `dimension_windows` | 素养同章节五事件聚合窗口 | 素养投影器 |
| `state_projection_log` | 每次投影 before/after（幂等，离线重放） | 投影器 |

### 可视化与工具追踪（3 张）

| 表 | 用途 | 主要读写 |
|----|------|---------|
| `math_visualizations` | 数学可视化 spec 产物（kind / spec_json / animation_recipe_json） | 工具 artifact_handler 写入 |
| `animation_jobs` | 动画渲染任务（RQ 入队，queued→completed/failed） | visualization 服务 |
| `tool_call_traces` | 工具调用轨迹（round_index / tool_name / status / arguments_summary 脱敏） | ToolRuntime trace_handler 写入 |
