## 今晚可聊的主线

可以把智学助手介绍为一个“已经能产生学习过程数据的真实 AI 导学系统”，请张老师重点判断：

1. 哪些行为数据值得采集；
2. 哪些指标适合作为效果验证；
3. 小规模试点中是否需要加入困难感/熟悉感自评；
4. 是否可以把学生使用过程建模成事件序列；
5. 研究生如果参与，应主要负责试点设计、数据分析、评价指标和效果验证报告。
