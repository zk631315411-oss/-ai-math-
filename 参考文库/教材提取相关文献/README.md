# 教材提取相关文献索引

> 下载日期：2026-06-12
> 主题：教材知识图谱、概念抽取、先修关系、教育知识图谱 schema / ontology

## 优先阅读

1. `2016_Using_Prerequisites_to_Extract_Concept_Maps_from_Textbooks.pdf`
   - 教材 concept map 抽取，关注目录结构、章节顺序和先修关系。
   - 对当前 `PREREQUISITE_OF` 的定义很有参考价值。

2. `PREAP_2024.pdf`
   - 先修关系标注协议，重点是“什么才算 prerequisite relation”。
   - 适合用来制定关系判断标准和正反例。

3. `2019_Concept_Extraction_and_Prerequisite_Relation_Learning_from_Educational_Data.pdf`
   - 同时讨论概念抽取和先修关系学习。
   - 对“知识点/概念”的抽取粒度有参考价值。

4. `2020_Digging_Into_Prerequisite_Annotation.pdf`
   - 深入讨论先修关系人工标注的一致性和边界。
   - 可用于补充 `PREREQUISITE_OF` 的严格判准。

5. `2022_Automatic_Construction_of_Concept_Maps_from_Unstructured_Text.pdf`
   - 从非结构化文本构建概念图。
   - 对 Step 2b 的 LLM 自由抽取后处理有参考价值。
