## 一、我们站在哪里

### 我们的核心优势（文献验证过的）

1. **##### 锚点 = 免费的概念边界标注**。Wang 2016 需要 Wikipedia 做概念映射，Lu 2019 需要 AutoPhrase + 图传播筛领域概念，Chen 2018 需要 CRF 训练 245 句→F1=0.77。我们结构化 MD 的 `#####` 标题直接给出 100% 准确的实体边界——这是竞品没有的结构优势。

2. **纯文本特征可行**。Miaschi 2019 验证了只靠文本内容（不靠 Wikipedia 图结构）就能判前置关系。我们的 Step 5 LLM 判关系方案有学术支撑。

3. **两段式架构公认正确**。Lu 2019 (DsCE→iPRL)、Gul 2022 (concept extraction→difficulty→coverage edges) 都采用先抽概念再判关系的设计，和我们的 Step 2→Step 5 一致。

### 学术界公认的天花板

- **前置关系自动检测 F1 上界 ≈ 0.61**（Wang 2016，6 学科平均）。我们对 Step 5 的期望不宜过高。
- **人工标注一致性极低**：5 位专家全票通过仅 3%（Alzetta 2020）。这告诉我们——前置关系本身的"正确答案"就是模糊的。我们不应该追求完美，而应该追求**有据可查**（每条边有 evidence）。

## 二、对提取规则设计的五条约束

### 约束 1：概念定义必须严格（来自 Alzetta 2020）

"Not a Concept"是第一大标注错误。我们的提取规则必须明确：
- ✓ 教材明确定义的术语 → 抽
- ✓ 教材首次引入的数学对象/操作/性质 → 抽
- ✗ 普通词汇（"情况""方法""问题"）→ 不抽
- ✗ 教材外常识（"整数""实数集"）→ 不抽

### 约束 2：关系必须有文本证据（来自 PREAP 2024 + Alzetta 2020）

"Background Knowledge"是第二大错误——标注者凭自己知识加的关系不在教材里。我们的 evidence 字段必须从教材原文引用，不能靠 LLM 自己猜。

### 约束 3：词法型关系 > 功能型关系（来自 Alzetta 2020）

词法关系（上下位、整体-部分）一致性 >60%，功能关系（因果、时序）一致性低。Step 5 可以按此分置信度。

### 约束 4：前置依赖的三条属性（来自 PREAP 2024）

- 反身性禁止：A 不是 A 的前置
- 非对称性：A≺B ⇒ ¬(B≺A)
- 传递性：A≺B ∧ B≺C ⇒ A≺C（可推理，不显式标注）

### 约束 5：顺序一致性是最强信号（来自 Wang 2016 + Lu 2019）

前置概念在教材中严格先于目标概念出现。我们的 `section_id` 天然有序，这个特征零成本可用。

## 三、对我们的技术架构建议

### Step 2 概念提取

- 保持正则 + LLM 自由提取（宁滥勿缺）
- 正则规则需按约束 1 收紧过滤条件
- LLM prompt 需加入约束 1 的细则

### Step 3 归一化

- 可借鉴 Lu 2019 的图传播排序：规则实体高置信→推高相近 LLM 实体置信度
- 同义词归并（"m级矩阵→方阵"）

### Step 5 关系判断

- 加入 Lu 2019 的 A↔F 迭代机制：第一轮 LLM 判 → 传递性补边 → 第二轮 LLM 再判
- 按约束 3 分置信度（词法高/功能低）
- 每条边必须有 evidence 引用教材原文
- 边类型只保留 PREREQUISITE_OF / DERIVED_FROM / APPLIES_TO

### 前端可视化

- 参考 Guo 2025 的环状布局设计
- 节点大小映射连接数（重要性）
- 引用调查数据（92% 学生认可环状展示）
