## 一、概念定义

> 概念 = 教材中出现的领域术语（domain terms），在给定上下文中具有明确的学科含义。

### 1.1 必抽条件

| 条件 | 判断方法 | 正例 |
|------|---------|------|
| **A. 明确定义** | 正文中出现 "称为/叫做/记作/称X为Y" 句式引入的新术语 | 矩阵、零矩阵、阶梯形矩阵、方阵 |
| **B. 首次命名** | 教材首次引入，后续章节会反复使用的数学对象 | 线性方程组的初等变换、主元 |
| **C. 别名/特化** | 同一概念的不同名称或特殊情况（标注同义关系→Step 3 归并） | m级矩阵→同义于方阵 |
| **D. 命名方法/算法** | 正文中出现 "XX 法/XX 算法/XX 变换" 等命名模式 | 高斯-约当算法、矩阵消元法 |
| **E. 定理/公式（见 §1.3）** | 见下文分层规则 |

### 1.2 绝对不抽

| 不抽 | 原因 | 正例 |
|------|------|------|
| 教材外常识 | 非本书定义 | 复数集、实数集、整数集、有理数集 |
| 纯描述性短语 | 非术语 | "元素全为0的行"、"非零行的数目" |
| 动词/操作名 | 不构成概念名 | "消去"、"互换"、"数乘" |
| 编号占位符 | 编号不能作为实体名 | "定义1"、"定理1"、"例1" |
| 过于通用的词 | 无学科特异性，Alzetta 2020 "Not a Concept" | "问题"、"方法"、"情况"、"可能" |

### 1.3 定理/公式/推论/引理的分层规则

> 核心原则：**编号不是实体名。抽的是语义内容，不是排版标签。**

| 层 | 条件 | 处理 | 例子 |
|----|------|------|------|
| **第一层** | 有通用名称，跨教材稳定存在 | 抽，用通用名 | name="克莱姆法则", type=Formula; name="Schur引理", type=Theorem |
| **第二层** | 编号定理，但数学断言重要 | 抽，生成语义名。格式：**对象 + 条件/操作 + 结论**。编号进 source_label，短名放 alias | name="矩阵可经初等行变换化为阶梯形矩阵", alias=["矩阵化为阶梯形"], type=Theorem, source_label="定理1(§1.1)" |
| **第三层** | 编号推论/命题/引理，**引入了新的可复用结论**（常用判据、等价条件、公式、方法，或被后文反复引用） | 抽，生成语义名 | name="齐次线性方程组有非零解的判别准则", type=Theorem, source_label="推论1(§1.2)" |
| **第三层补充** | 若只是主定理的直接改写、局部特例、证明中间步 → 不抽 | 内容进前置定理节点的 evidence | — |
| **第四层** | 纯证明工具，后文不再引用 | 不抽，内容最多进入 evidence | — |

**命名格式要求**：
```json
{
  "name": "矩阵可经初等行变换化为阶梯形矩阵",  // 完整语义名
  "alias": ["矩阵化为阶梯形", "矩阵→阶梯形"],   // 检索用简称
  "type": "Theorem",
  "source_label": "定理1(§1.1)"                // 原始编号+位置
}
```

### 1.4 属性值 vs 独立概念

> 默认规则：如果只是某个父概念在某个分类维度下的取值 → 属性值，不抽。

以"线性方程组解的情况"为例：`唯一解`、`无穷多个解`、`无解` 默认为属性值。

**升级条件（满足任一即升级为实体）**：

| 条件 | 说明 |
|------|------|
| 教材对该状态单独给出定义 | 如 "齐次线性方程组的零解" 被明确定义 |
| 有独立判别准则 | 如 "无解 ⇔ 增广矩阵的秩 > 系数矩阵的秩" |
| 参与多个关系边 | 在 KG 中需要作为桥节点 |
| 后文以它为主题展开 | 整节/整章讨论该状态 |

### 1.5 概念类型

| 类型 | 定义 | 正例 |
|------|------|------|
| **Definition** | 教材明确给出定义的概念 | 矩阵、零矩阵、阶梯形矩阵、方阵 |
| **Theorem** | 有语义名的定理/推论/命题/引理（非编号） | 克莱姆法则、矩阵可化为阶梯形定理 |
| **Formula** | 有名称的重要公式 | 牛顿-莱布尼茨公式、克莱姆法则 |
| **Method** | 有名称的算法/变换/解法 | 高斯-约当算法、矩阵的初等行变换 |
| **Concept** | 不属于以上的其他学科术语 | 解集、同解、自由未知量、线性方程组 |

### 1.6 名字规范化

- 取教材原文中**最短、最常见**的中文表达
- 优先用不加定语的简称："矩阵" 而非 "s×m 矩阵"
- 同义词取教材首选名，其余标同义→Step 3 归并
- LaTeX 清理：`$s \times m$` → `s×m`（Unicode ×）
- 纯英文→中文：`Skew_Symmetric_Matrix` → `反对称矩阵`

## 二、关系定义

### 2.1 只保留两种关系

| 关系 | 方向 | 含义 | 判断标准 |
|------|------|------|---------|
| **PREREQUISITE_OF** | 前置→后置 | 必须先学 A 才能理解 B | (1) B 的正文中引用/使用了 A，(2) A 的 section_id ≤ B 的 section_id，(3) 有教材原文 evidence |
| **DERIVED_FROM** | 源→目标 | A 推导出/特殊化得到 B | B 的正文中有推导句式（"称为"、"记作"、"由...得到"、"A 的...称为 B"） |

### 2.2 三种关系属性（PREAP 2024）

- **反身性禁止**：A 不是 A 的前置
- **非对称性**：A≺B ⇒ ¬(B≺A)
- **传递性**：A≺B ∧ B≺C ⇒ A≺C（可推理，不显式标注）

### 2.3 置信度分层（来自 Alzetta 2020）

| 关系类型 | 置信度 | 
|---------|--------|
| 词法型（上下位、整体-部分、同义） | **高** |
| 功能型（因果、时序、应用） | **低** |

### 2.4 不创建的关系

| 关系名 | 原因 |
|--------|------|
| RELATED_TO | 过于模糊 |
| HAS_ANSWER | ##### 题/答案自然配对 |
| USES_CONCEPT | 过于泛化，信息量为零 |

## 四、原则性总结

> **宁缺毋滥**：不确定的不抽（Alzetta 2020: "Not a Concept" 是第一大错）
> **编号不是实体名**：Theorem 类型保留，但命名必须语义化
> **有据可查**：每条边必须有教材原文 evidence
> **顺序优先**：前置概念必须先于目标概念出现（Wang 2016）
