# 教材提取模块

为「学数有道」平台把教材构建为 Neo4j 知识图谱（KG）。当前推荐路径是 v4.4 多轮 LLM 流水线，高等代数、高等数学均已迁移到该版本。

## 当前状态

| 教材 | 状态 |
|------|------|
| 高等代数（上/下册，丘维声） | **v4.4 已部署**，当前线上 KG 来源：2980 节点 / 4396 边（9 节点类型 / 16 边类型） |
| 高等数学（上/下册，黄立宏） | v4.4 工作区已就绪（上/下册 + 隐式边增强），尚未部署 |

## 分区约定

| 分区 | 放什么 | 不放什么 |
|------|--------|---------|
| 工作区（高代提取/ 高数提取/） | 各自教材的 v4.4 脚本与中间产物 | 跨教材共用代码 |
| `正式脚本/` | 历史方案归档与脚本副本（不再推荐使用） | 当前流水线产物 |

## Neo4j 消费端

KG 由以下四个模块消费，Schema 设计需满足其字段需求：

| 模块 | 文件 | 功能 |
|------|------|------|
| 知识图谱可视化 | `app/routers/auth.py`（`GET /api/auth/knowledge-graph`） | 薄弱概念 → 前后置依赖 |
| 前置知识检查 | `app/services/prerequisite_checker.py` | 学某节前查前置是否掌握 |
| 白名单生成 | `app/db/whitelist_db.py` | 当前章节允许使用的知识点范围 |
| 诊断溯源 | `app/db/diagnostic.py` | 章节概念列表 + 前置链 |

## 思路变动历史

| 版本 | 思路 | 位置 |
|------|------|------|
| KG v2（早期） | LLM 全块抽取（GLM-4.5-Air），一次性产出全部节点与边 | `正式脚本/归档/legacy_pre_v4_1/build_kg.py` |
| v4.1 / v4.2（规则化） | 拆分为节点候选、规则化关系抽取，引入边审批清单；条件判断开始与普通边区分 | `正式脚本/归档/v4_1/`、`v4.2/` |
| v4.3（过渡） | 在 v4.2 基础上加入应用验证（Step 9） | `正式脚本/归档/v4.3/` |
| v4.4（当前） | 多轮 LLM 流水线：规则案例（RuleCase）独立成层、AI 审核门禁（Step 7B/7C）、确定性知识组（KnowledgeGroup）、REFERS_TO 回连、Neo4j 导入 + 应用验证 | `高代提取/`、`高数提取/` |

当前高代、高数均已采用 v4.4；v2/v4.1/v4.2/v4.3 保留在 `正式脚本/归档/` 仅作历史参考。
