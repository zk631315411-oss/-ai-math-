# 提取规则待明确

> 2026-06-10 | Step 2 抽取质量优化的前置问题

## 核心问题

当前的 Step 2a（正则规则）和 Step 2b（LLM 自由提取）都在没有统一标准的条件下运行。导致：

- 同一个概念 "矩阵" 被抽成 s×m矩阵 / 矩阵 / 矩阵的元素 三种形态
- "唯一解"、"无穷多个解"、"无解" 各自独立成节点，而不是归为 "线性方程组解的情况" 的一个属性
- 定理 1 的断言 "矩阵可经初等行变换化为阶梯形矩阵" 是否应作为实体、作为哪类实体，没有定论
- "一元一次方程" 这种初中知识被抽进来了，而真正的高等代数概念反而遗漏

## 需要明确定义的问题

### 1. 概念抽取的粒度

什么算一个独立概念，什么算已有概念的附属表述？

| 原文 | 当前产出 | 问题 |
|------|---------|------|
| "由 s·m 个数排成 s 行、m 列的一张表称为一个 s×m 矩阵" | 抽到 "s×m矩阵" | "矩阵" 本身应该是一个独立概念吗？ |
| "元素全为0的矩阵称为零矩阵" | 抽到 "零矩阵" | 正确：这是矩阵的特殊形态 |
| "第 i 行与第 j 列交叉位置的元素称为矩阵的 (i,j) 元" | 抽到 "矩阵的(i,j)元" | 太细了——这是 "矩阵元素" 的一个子概念 |
| "称它为方阵。m 行 m 列的方阵也称为 m 级矩阵" | 抽到 "方阵" + "m级矩阵" | "m级矩阵" 是 "方阵" 的同义词，应该归一 |

### 2. 实体类的划分

当前 5 种类型：Definition / Theorem / Formula / Method / Concept。什么情况归哪类？

| 情况 | 困惑 |
|------|------|
| "线性方程组的初等变换" | 是 Method（方法）还是 Definition（定义）？ |
| "高斯-约当算法" | 是 Method 还是 Theorem？ |
| "唯一解" / "无穷多个解" / "无解" | 是各自独立的 Concept，还是 "解的情况" 这个父概念的子属性？ |
| 定理/命题/推论/引理 | 之前决定不作为独立节点。那 Theorem 类型还有什么用？ |
| "复数集"、"实数集"、"有理数集" | 它们是已知的数学对象，不是本书定义的。应该抽吗？ |

### 3. 跨节实体的重名处理

同一个名字在不同节可能指不同东西：

| 名字 | 实际情况 |
|------|---------|
| "定理1" | 每节都有一个定理1，18 个同名不同物 |
| "例题1" | 每节都有例1 |

当前 Step 1 已用 `_序号` 后缀消歧（如 `定理1_1`、`定理1_2`）。但归一化后 node name 只有一个，必须用更大粒度的命名。

### 4. 关系的判断标准

三个关系的严谨定义待写：

- `PREREQUISITE_OF`：什么程度才算 "前置"？同节内概念自然有先后，是否都连前置？
- `DERIVED_FROM`：定理 A 引用定理 B，就算推导关系吗？
- `APPLIES_TO`：和 USES_CONCEPT 的边界在哪？
